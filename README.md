# OpenCart Manual Testing Project

A complete manual QA testing suite for [OpenCart](https://demo.opencart.com/), covering test planning, test case design, and execution documentation for a real-world e-commerce application.

## Overview

This project simulates a full manual testing engagement — from writing a formal test plan to designing and documenting test cases across 30+ functional modules of OpenCart, including registration, login, product browsing, cart, checkout, and account management.

## Key Features

**Test Plan**
A structured test plan covering scope, test strategy, environments, roles, entry/exit criteria, and risk mitigation — following standard STLC practices.

**Test Cases**
300+ test cases spanning user registration, login/logout, product search, cart, checkout, wishlist, order history, and admin functions. Cases are organized by module and mapped to test scenarios for easy navigation.


**Test Scenarios**
Step-by-step scenarios covering key user journeys, ensuring consistent execution and thorough coverage across testers.

**Expected Results**
Every test case defines a clear expected result, making it easy to spot bugs, regressions, or inconsistent behavior.

**Defect Reporting**
A standardized reporting template for logging bugs — including steps to reproduce, screenshots, and issue descriptions.

## Test Design Techniques Used
- Equivalence Class Partitioning
- Boundary Value Analysis
- Decision Table Testing
- State Transition Testing
- Exploratory Testing & Error Guessing

## Tech / Tools
- Excel (Test Case & Defect Documentation)
- Manual Functional Testing
- Cross-browser Testing (Chrome, Firefox, Edge, Safari)

## Target Audience

QA engineers, test leads, and anyone looking for a reference example of end-to-end manual testing documentation — from planning through execution.
